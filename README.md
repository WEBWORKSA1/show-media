# SHOW.MEDIA — show.media

Independent "what to watch" streaming hub: trending charts, Stream-It-or-Skip-It verdicts, trailers, Creator Spotlight, contests, live events, reader support and a direct sponsorship pipeline. Static HTML/CSS/JS — no backend — hosted free on GitHub Pages.

## Structure
- `*.html` — 28 pages generated by `build.py` (edit `build.py`, run `python3 build.py`).
- `assets/js/config.js` — **the only file you need to touch to go live**: AdSense IDs, affiliate links, YouTube playlists, support links, socials, form endpoint.
- `assets/js/app.js` — runtime: catalogue rendering, search, filters, forms, ads, theme.
- `assets/data/shows.json` — the catalogue (add/replace titles here).
- `docs/PHASE-WISE-BUILD-PROMPT.md` — the phase-by-phase build prompt.
- `docs/COMPETITOR-RESEARCH.md` — 36-site teardown and feature matrix.
- `CNAME` — custom domain `show.media`. `.github/workflows/pages.yml` — auto-deploy.

## Go-live checklist
1. **Forms**: submit any form once; FormSubmit e-mails a one-time activation link to the inbox — click it. All forms then deliver to that inbox. (The address is stored obfuscated in `config.js` and never appears in the HTML.)
2. **AdSense**: after approval set `adsense.enabled = true`, paste your `ca-pub` client and slot IDs, and replace the line in `ads.txt`.
3. **Affiliate links**: replace `affiliate.*` URLs with your tracking links.
4. **Support**: point `support.*` to your Ko-fi / Buy Me a Coffee / PayPal / GitHub Sponsors pages; update `goalRaised` monthly.
5. **Video**: swap `youtube.playlists` for your channel's uploads playlist (`UU` + channel-ID suffix) and set `channelUrl`.
6. **DNS for show.media**: A records → 185.199.108.153 / .109.153 / .110.153 / .111.153; CNAME `www` → `webworksa1.github.io`. Then Settings → Pages → Enforce HTTPS.
